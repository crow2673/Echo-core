# Self-Evolution Protocol v0.3

The experiment now treats self-improvement as an engineering claim that must
be demonstrated, not merely described.

## Required path

1. Observe a limitation.
2. State a falsifiable hypothesis.
3. Build a candidate.
4. Reject candidates that fail the static safety gate.
5. Establish a baseline benchmark.
6. Run the same benchmark against the candidate.
7. Require the candidate to beat the baseline.
8. Record the candidate hash and evidence.
9. Promote only after the evidence gate passes.
10. Keep a rollback copy of the previous implementation.

A model saying "this is better" is **not evidence**.

A syntax check is **not evidence**.

The benchmark must measure the capability the change claims to improve.

This is the first point where the system can begin distinguishing
*self-modification* from *self-improvement*.
